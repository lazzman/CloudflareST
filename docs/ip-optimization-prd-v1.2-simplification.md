# IP 优选管理：v1.2 简化主流程（CR-002）

日期：2026-11-16。基线为PRD v1.0、v1.1/CR-001及R3；原稿保留。本次用户明确要求降低复杂度，以“定时执行指定策略、查看策略IP结果、按延迟/速度排序”为核心，并选择“A：DNS与通知保留但收起”。

## 已确认的变更

- 默认主路径只有“策略列表→IP结果”，一点击结果，无须先经过概览和记录页。
- 策略列表呈现名称、计划与启停、最近运行状态；支持运行一次、查看结果、编辑。归档等收在更多操作。
- 结果默认打开最近一次运行（失败或无结果也如实展示，不静默回退较早成功记录），历史运行通过顶部时间选择器切换。
- IP表格以IP、延迟、下载速度、失败比例为主；列头升降序作用于整份所选运行结果、然后分页。默认合格IP，可切换全部候选；无指标显示未测，不当作0。查看排序不改原排名、快照、DNS选IP或触发执行。
- 普通编辑仅突出名称、来源、过滤门槛和计划；测速细节、预算、DNS/通知收在高级设置。已有高级配置原样保留；隐藏字段校验失败必须可展开定位，不能静默重置。
- DNS/通知不关闭、不删除，已开启的自动动作继续工作；运行前和结果出现推送异常时仍有简短提示。详细诊断、投递、日志、队列及回收站均保留在高级入口，旧深链接兼容。
- 保存不自动运行或偷偷开启定时；列表可直接开关计划。共享密码、Docker、队列/取消/幂等/未知结果保护不改变。

## 验收边界

从列表一次点击看到最新结果表；可原地换历史、点击列头排序；数据量跨页排序正确，空值后置。定时开关只改计划不影响DNS/通知；编辑简单字段不丢已有高级配置；不凭隐藏界面移除安全校验或清理数据。旧页面保留为高级兼容入口，而非日常必经路径。

当前阶段为此确认范围内的交互实现与定向复验，实施记录另存。无新增外部操作授权，所有验证使用本机替身或临时库。
