# 自动刷新引起页面抖动：修复与复验

日期：2026-11-17。范围为策略列表的周期性上下位移，不改变任务、计划或投递规则。

## 复现与原因

- 资源每两秒自动读取时都进入 loading 状态。页面把“最后读取”替换为加载提示，二者分别为 12 px／14 px，行高变化使整张策略卡片移动。
- 使用本机替身、每次请求延迟 450 ms，逐帧记录两次实际轮询：1440 px 浅色下卡片及表格顶部往返移动 3.203125 px；行节点保持，排除整表重建为本次根因。

## 修复

- useResource 区分首次／显式读取 loading 和已有数据的后台刷新 refreshing；后台更新保留当前数据、布局和操作状态，仍按原规则轮询，不通过停用实时更新规避问题。
- ResourceState 保留最后成功读取的时间行；手动刷新有忙碌状态及无障碍提示，不用不同高度的文本替换时间行。
- 策略卡片通过 aria-busy 标记后台更新，不添加占高提示，不周期性禁用刷新按钮。
- 错误仍显示“数据可能已过时”，保留旧数据及原成功时间；重试成功才清除提示。切换查询清除旧数据、旧时间和旧错误，迟到响应仍受序号保护；401 后不自动重试。

## 影响与边界

- 代码：internal/management/web/src/lib/useResource.ts、components/ResourceState.vue、pages/TaskListPage.vue；未修改后端或数据库。共享资源读取的后台提示行为同步修正。
- 真实数据增减、文本内容变化、错误出现等仍可能合理改变布局；本次保证的是内容未变化时，自动刷新不再重复插入不同高度的加载提示。
