# IP 优选管理：v1.3 操作结果自动确认（CR-003）

日期：2026-11-19。基线为 PRD v1.0、v1.1/CR-001、v1.2/CR-002 及 R3；原稿保留。本变更只调整“写入结果不确定”时的前端交互，不改后端幂等、操作收据、权限和外部操作边界。

## 已确认的变更

- 删除顶栏全局待确认入口、数量角标和人工恢复许可界面。
- 保留后端 `Idempotency-Key`、操作收据、同号重放和恢复接口；管理界面不再调用人工恢复接口。
- 写入超时、断网、5xx、响应无法解析或服务端返回未知状态时，前端自动读取原操作收据一次。
- 收据已有确定结论（completed／accepted 等）时直接采用该结果，清理本地待确认记录，不再要求用户手工查询。
- 收据为 unknown／expired／unconfirmed、查询失败或仍无法确认时，保留原操作号；再次提交同一动作沿用原号，不生成新号。
- 未确认结果只在对应任务、执行、连接、系统设置、运行列表／队列／结果页或 DNS 目标详情提示；不常驻顶栏，不阻断无关动作。
- 连接动作摘要包含非敏感字段和凭据字段名，不摘要或持久化秘密值；不同连接内容使用不同操作号。
- 旧版缺少动作范围的待确认记录不再恢复拦截；新记录始终保存动作范围。

## 用户可见行为

| 场景 | 行为 |
| --- | --- |
| 保存／触发／删除等写入超时 | 自动读取原操作收据；确认后按该结果更新页面，不重复提交 |
| 收据仍未知、过期或查询中断 | 页面显示“写入结果未确认”，保留原操作号；用户可再次提交，系统沿用原号 |
| 连接新建／修改 | 不同非敏感内容使用不同操作号；只改秘密值时沿用同号，秘密值不进入本地存储或摘要 |
| 切换到无关页面 | 不显示全局未确认角标；只有与操作对象匹配的页面显示提示 |
| 操作日志 | 仍为只读审计记录，不作为确认写入结果的替代入口 |

## 验收

| 编号 | 验收标准 |
| --- | --- |
| AC-CR003-01 | 顶栏不存在全局待确认按钮或数量角标 |
| AC-CR003-02 | 响应丢失但服务端已有收据时，前端自动读取并采用收据，不产生第二个写入请求 |
| AC-CR003-03 | 查询不到收据时保留原操作号；同一动作再次提交复用原号，不生成新号 |
| AC-CR003-04 | 不同连接内容使用不同操作号；本地存储不包含秘密值 |
| AC-CR003-05 | 未确认提示只在对应任务、执行、连接、设置或 DNS 目标页面出现，无关页面不显示 |
| AC-CR003-06 | 后端幂等、同号重放和恢复接口测试继续通过；管理界面不再发起人工恢复请求 |

定向验证：`npm run build`、`npm test`、`npm run test:browser:http`、`npm run test:browser:fixes`、`node scripts/test-management-fixes.mjs`、`node scripts/test-management-rc-fixes.mjs`。

## 影响与不做的事

- 不改变后端写入事务、操作号格式、收据保留、权限检查或外部 DNS／通知边界。
- 不把“查不到收据”解释为“未执行”，也不自动换号重做。
- 不恢复顶栏全局入口，不新增独立结果确认页面或人工许可流程。
- 历史验收报告和校验快照保留原样；本 CR 是当前需求口径。
