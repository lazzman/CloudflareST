## 使用流程与保护边界

1. 首页仅突出策略名称、定时计划、最近运行和“查看结果／运行一次／编辑”，定时在行内直接启停。详细管理菜单默认折叠。
2. 进入结果直接显示最近一次运行；失败或无结果不回退旧成功记录。历史通过顶部时间选择器及每页 20 条历史翻页切换，当前选择不被轮询覆盖。
3. IP 表格显示延迟、下载速度、失败比例。列头切换升降序；后端先排序全部匹配结果，再按每页 50 个分页；延迟相同时速度高者在前，缺失指标后置。资格和地址族可筛选。
4. 编辑只突出来源、筛选条件、定时计划；次数、超时、URL、预算、自动推送等收在高级设置。保存不触发运行，也不自动开启计划。高级字段仍保存原值，错误自动展开并定位。
5. 阅读排序不修改原排名、配置快照或 DNS 选 IP；定时开关不改 DNS／通知。已开启自动动作继续工作，列表有提示，投递异常有简短提醒及高级处理入口。
6. 活动运行可停止；取消、幂等、未确认收据、目标保护、旧链接和回收站不因简化而删除或绕过。
