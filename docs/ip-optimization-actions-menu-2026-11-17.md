# 策略操作：直接平铺显示

日期：2026-11-17。本页已按用户“没必要收起”的反馈更新，覆盖同日早先的浮层菜单方案；范围仅为策略列表操作区。

## 当前设计

- 移除“更多”触发按钮和浮层，删除菜单定位、开合、全局事件与键盘代理代码。
- “查看结果／运行一次／编辑”为常用按钮；定时开关、高级管理、归档／恢复直接展示。高级管理与归档采用相同的轻量文字按钮样式，统一字号、高度、内距。
- 手机操作区使用整张卡片的内容宽度，自然换行，不缩成图标、不隐藏操作，也不改变其他信息行的布局。
- Tab 顺序沿用原生链接和按钮。归档仍需二次确认，取消回到归档按钮；排队／运行中不可归档；恢复后定时关闭，不立即执行。
- 不修改接口、业务规则、配置或历史；DNS／通知等高级配置的原有收起方式不受影响。
