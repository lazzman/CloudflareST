# 编辑页分区改造与复验

日期：2026-11-17。用户反馈编辑页过长，需要滚动很久。本轮保留字段与保存契约，只调整配置页组织和可达性。

## 实现结论

- 主区为“基本信息／筛选条件／定时计划／高级设置”，可直接切换，不是必须逐步完成的向导。默认只展示基本信息。
- 高级区为“测速细节／下载设置／抽样预算／DNS 与通知”，不再同时展开成长页。CIDR 独立初采数量紧邻对应来源，仅 CIDR 行显示。
- 使用同一份表单状态，隐藏采用 v-show；切换不触发保存、运行或推送，未保存输入保持。底部保存条采用 sticky，保留正常滚动与数据输入。
- 保存仍校验全部字段。错误摘要获得焦点，并显示第一个错误所在分区；点击摘要链接切换主区及高级子区后定位字段。分区有错误数量提示。
- 标签页使用关联的 tab／tabpanel、选中状态、单一 Tab 入口；支持方向键、Home／End 与 Tab 进入当前面板。
- 原版本冲突、原操作号、幂等、未确认保护、路由离开确认、DNS／通知、默认计划开关与接口保持。没有后端或数据库迁移。
